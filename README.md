# Food Cost ERP Pro 🍱

نظام احترافي متكامل لإدارة تكلفة وتشغيل قاعات الأفراح وشركات التموين باستخدام Microsoft Excel.

## 🌟 المميزات الرئيسية
- **تصميم Modern Luxury:** واجهة مستخدم فاخرة باللونين الأسود والذهبي.
- **دعم كامل للغة العربية:** واجهة RTL متوافقة مع احتياجات السوق المحلي.
- **إدارة شاملة:** يغطي النظام كافة جوانب التشغيل من المشتريات والمخازن إلى المبيعات والربحية.
- **أتمتة ذكية:** حسابات تلقائية لتكلفة الوصفات (Recipe Costing) وتوسيع المقادير (Scaling).
- **لوحة تحكم (Dashboard):** مؤشرات أداء KPI ورسوم بيانية لمتابعة حالة العمل لحظياً.

## 📊 محتويات النظام (25 ورقة عمل)
1. **Dashboard:** ملخص الأداء المالي والتشغيلي.
2. **Packages:** إدارة باقات الأسعار (70، 85، 100، 130، 150 ريال).
3. **Food Categories:** تصنيفات الطعام.
4. **Master Food Database:** قاعدة بيانات الأصناف الجاهزة.
5. **Ingredients Database:** قاعدة بيانات المواد الخام والأسعار.
6. **Suppliers:** إدارة بيانات وتقييم الموردين.
7. **Recipe Cards:** بطاقات تكلفة الوصفات التفصيلية.
8. **Recipe Scaling:** تحجيم الوصفات حسب عدد الضيوف.
9. **Menu Builder:** بناء قوائم الطعام للعقود.
10. **Food Cost Calculator:** حاسبة تكلفة الفرد والربحية.
11. **Operational Cost:** المصاريف التشغيلية (غاز، كهرباء، عمالة).
12. **Inventory:** إدارة المخزون وتنبيهات النقص.
13. **Purchase Orders:** أوامر الشراء.
14. **Sales:** إدارة عقود العملاء والدفعات.
15. **Profit Analysis:** تحليل الأرباح الشهري والسنوي.
16. **Food Waste:** تتبع الهدر وأسبابه.
17. **Reports:** تقارير جاهزة للطباعة PDF.
18. **Charts:** رسوم بيانية تحليلية.
19. **Settings:** إعدادات النظام العامة.
20. **User Guide:** دليل الاستخدام السريع.
21. **Staff:** بيانات الموظفين والرواتب.
22. **Maintenance:** سجل الصيانة للمعدات.
23. **Equipment:** الأصول والمعدات.
24. **Utilities:** استهلاك المرافق.
25. **Logs:** سجل العمليات.

## 🚀 كيف تبدأ؟
1. افتح ملف `Food_Cost_ERP_Pro.xlsx`.
2. ابدأ بتعريف الموردين في ورقة **Suppliers**.
3. أدخل المواد الخام في **Ingredients Database**.
4. قم ببناء وصفاتك في **Recipe Cards**.
5. استخدم **Menu Builder** لتسعير حفلاتك القادمة.
